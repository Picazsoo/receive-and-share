# Receive & Share for Kobo Libra 2, version 0.2

Prerelease. Tested on Kobo Libra 2 with firmware 4.38.23697.

## Changes

- Search ignores case and diacritics in the enhanced browser, basic view and Kobo sharing settings. For example, `ohnivy` matches `ohnivý`, and `zlaty rez` matches `Zlatý Řez`.

- Optional EPUB-to-KEPUB conversion using kepubify. Off by default. PDFs and existing KEPUBs pass through unchanged. If conversion fails, the enhanced browser can send the original EPUB instead.
- Bulk deletion of shared books. Separately enable **Allow deleting shared books** on the source Kobo, then select and review books in the browser. Permission resets each session; Share all does not enable it.
- Deletion confirmations show filenames, paths, types and sizes. Changed files are refused, results are reported per file, and retrying a completed deletion cannot delete a replacement at the same path.
- The finished page lists received and successfully deleted books separately.
- Port 80 omits the port number from the address. Displayed addresses and QR links omit the trailing slash. The port remains configurable; the default is still 8080.
- Startup requires Wi-Fi to be on and connected. If it is not, the Kobo asks you to connect and try again. It does not choose a network or enable Wi-Fi during startup.
- Reopening a session resets the old browser-close timer. Launcher messages now fit the Kobo toast, and the server is checked before opening the browser.
- Startup diagnostics and saved finish-test pages now go to `/tmp` instead of the book-scanned storage.

## Before installing or upgrading

Follow [Keep application files out of My Books](https://github.com/Picazsoo/receive-and-share/blob/main/docs/USAGE.md#keep-application-files-out-of-my-books)
before installing. Kobo can index supported files inside `.adds`, even though it is
a hidden folder. The installer does not change your Kobo configuration.

If support files already appear as books, back up the app before adding the
exclusion. Kobo may delete those files while removing their library entries;
restore missing support files from the backup after cleanup. Do not delete the
entries manually without a backup, since some are live app settings.

## Install

Finish any active session, connect by USB, and extract `Receive-Share-v0.2.zip`
on your computer. Choose one folder:

| Already installed | Folder |
| --- | --- |
| NickelMenu and NickelDBus, including an existing Receive & Share installation | `app-only` |
| NickelMenu only | `with-nickeldbus` |
| Neither | `first-install` |

Copy the chosen `KoboRoot.tgz`, without extracting or renaming it, into `.kobo`.
Safely eject, unplug and wait for installation and restart. Connect to Wi-Fi,
then open **NickelMenu → Receive & Share**. Reload and pair browser clients again.

Settings, the port preference, received books and other NickelMenu entries are
preserved. Dependency bundles replace their included helper binaries; use them
only for missing dependencies. The ZIP includes installer SHA-256 checksums; the
separate `.zip.sha256` file checks the whole download.

## Testing and limits

Local Go tests, browser-client tests, HTTP smoke checks and ARM builds pass.
Conversion, lost-acknowledgement handling, deletion, native library refresh,
port 80, Wi-Fi-off refusal and reopening were tested on the Libra 2 through SSH.
The Kobo updater installation cycle still needs a device test. Other models,
iOS, and download/import on a second Kobo also need testing. NickelMenu currently
does not support firmware 5.x.

Transfers use unencrypted local HTTP. Sessions last 20 minutes; uploads are limited
to 100 MiB per file. Conversion runs in a separate process with a 90-second timeout
and [archive limits](https://github.com/Picazsoo/receive-and-share/blob/main/docs/USAGE.md#optional-epub-conversion).
Only the converted copy is saved on the Kobo. Deletion is permanent and may remove
reading progress and annotations when the library refreshes.

Forks, PRs and testing on other Kobo readers are welcome. Please include the model,
firmware version and what worked or failed.
